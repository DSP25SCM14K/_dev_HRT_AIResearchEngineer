# Dev Kumar — Compute with intent

A responsive portfolio for Dev Kumar, focused on AI research engineering, GPU kernels, and large-scale model training and inference systems.

## Publish

This static site deploys to GitHub Pages through GitHub Actions on each push to `main` and on manual workflow runs. The repository root is the published site; no build step is required.

## Local preview

Open `index.html` in a browser or serve this folder with any static file server. The animated GPU-cluster illustration is a local SVG, and motion effects honor reduced-motion preferences.
